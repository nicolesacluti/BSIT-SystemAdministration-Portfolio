### 2. GitHub Repository Setup

**Problem:**  
When I first cloned my GitHub repository, I received a warning saying, "You appear to have cloned an empty repository." I initially thought there was an error with the repository.

**Solution:**  
I learned that the warning was normal because the GitHub repository was newly created and did not contain any files yet. I proceeded by creating the required folders and files locally, then committed and pushed them to GitHub.

### 3. VS Code / Git Configuration

**Problem:**  
I initially had difficulty navigating to the correct repository folder using PowerShell. I accidentally used the cd command while I was already inside the BSIT-SystemAdministration-Portfolio directory, which caused a "Cannot find path" error.

**Solution:**  
I checked the current directory shown in PowerShell and realized that I was already inside the repository. Instead of navigating into the folder again, I used code . to open the current repository directly in Visual Studio Code. This helped me understand how to navigate between directories and work with Git repositories using the terminal.
